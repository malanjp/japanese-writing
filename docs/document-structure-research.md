# 読みやすい文書構成の調査

「人間が読みやすく、頭に入ってきやすい文書構成」を規則として定義するために、認知心理学、文章理解研究、日本語の文章規範を調べた。
末尾に定義案を置く。

調査日は 2026-07-28。
出典は各節に示し、書誌情報は最後にまとめた。

## 調査の方針

「読みやすい」は主観語なので、そのままでは規則にできない。
そこで次の三つに分解した。

読み手の側にどんな制約があるか。
その制約に対して、文書構造の何が効くと実証されているか。
効果が条件付きだったり反証があるものはどれか。

三つ目を落とすと、根拠のない規則が混ざる。
実際、調べた範囲では「常に効く」と言える構造上の工夫はほとんどなかった。

## 1. 読み手の側の制約

### 1.1 一度に保持できる情報は少ない

Miller (1956) の 7±2 は広く知られているが、Miller 自身は厳密な容量の推定ではなく概算として提示していた。
Cowan (2001) は、リハーサルと長期記憶の支援を統制した条件で証拠を整理し、焦点的注意が保持できるのは平均して約 4 チャンクだと論じた。

ここで重要なのは絶対値ではなく、チャンクという単位である。
4 という数は「4 項目」ではなく「4 つのまとまり」を指す。
つまり構成の役割は、項目数を減らすことではなく、まとまりを作って数を減らすことにある。

### 1.2 負荷には減らせるものと減らせないものがある

Sweller の認知負荷理論は、負荷を三種類に分ける。

内在的負荷は題材そのものの複雑さから来る。
要素間の相互作用が多いほど大きく、読み手の予備知識によって変わる。
外在的負荷は提示の仕方が悪いために生じる、本来不要な負荷である。
学習関連負荷は、理解した内容を長期記憶の枠組みに組み込むために使われる。

文書構成が操作できるのは外在的負荷である。
内在的負荷を下げようとすると、内容を削ることになり、正確さを損なう。
この区別は、既存の SKILL.md が「短くすること」より「意味を保つこと」を優先している方針とも一致する。

### 1.3 読み手は要点を作りながら読む

Kintsch と van Dijk (1978) のモデルでは、読み手はテキストから命題を取り出し、ワーキングメモリの制約を受けながら循環的に処理する。
その過程で、削除、一般化、構成という操作を通じて、要点にあたるマクロ構造を作る。

書き手がマクロ構造を明示しなければ、読み手が自力で構築することになる。
これが構成の負担の正体である。
見出しや要約文は、この構築作業を肩代わりする装置として位置づけられる。

## 2. 文書全体の構造

### 2.1 上位に置いた情報ほど残る

Meyer (1975) は、同じ段落を階層構造の上位に置いた版と下位に置いた版で比較し、上位に置かれた情報のほうが再生されやすいことを示した。
配置の順序ではなく、論理構造上の位置が効いている。

日本語の規範でも同じ方向の指示がある。
文化審議会「公用文作成の考え方」(2022) は、結論をできれば最初の段落で示し、続けて理由や詳細を説明するとしている。
最後まで読まないと主旨が分からない書き方を避ける、という書き方をしている。

Minto のピラミッド原則も、結論を頂点に置き、その下に根拠を配置する点で同じ構造を取る。
Minto は下位の項目群に MECE を求め、順序として演繹、時系列、構造、比較の四つを挙げる。

### 2.2 見出しは骨組みとして機能する

「公用文作成の考え方」の解説は、見出しについて具体的な条件を挙げている。

標題には主題となる案件と、報告や提案といった文書の性格を入れ、1 行に収める。
見出しだけを読んでいけば、文書の内容と流れがおおよそつかめるようにする。
標題と見出しを呼応させる。
分量が多いときや論点が複数あるときに見出しを使い、短い文書では必ずしも必要ない。

最後の条件が効果の境界を示している。
Lorch と Lorch (1996) の実験がこれを裏づける。
話題構造が単純なテキストでは、見出しや要約といった signaling に効果が見られなかった。
構造が複雑な場合にだけ、再生の分布と組織化に影響が出た。

さらに、signaling があると想起できる話題の数は増えるが、話題ごとの詳細の想起は減った。
見出しは網羅性を上げ、深さを下げる。
何を優先するかで使い分けが変わる。

Mayer の signaling 原理はマルチメディア学習の文脈で中程度の効果量を報告しているが、再分析の対象が同一研究室の類似材料に偏っており、効果が過大に出ている可能性が指摘されている。

### 2.3 階層は入れ子構造として設計する

永井 (2023) は、パラグラフの内部構造と文章全体の構造が同型であることを基本ルールの一つに挙げている。
段落が「要点 + 支持」で構成されるなら、文書全体も「結論 + 根拠」で構成される。
節も同じ形を取る。

この同型性には実務上の利点がある。
どの粒度でも同じ判断基準を使えるため、規則の数が増えない。

### 2.4 分量は先に決める

「公用文作成の考え方」は、何文字または何ページにするかを決めてから書き始め、必要性の低い情報は分量調整の段階で削る、としている。
複数人で分担する場合は、事前に分担と分量を決めておく。

これは構成の規則というより、構成が崩れる原因への対処である。
分量の上限がないと、各部分が独立に膨らみ、全体の比率が壊れる。

## 3. 段落

永井 (2023) は、パラグラフ・ライティングに関する 61 件の文献を分析し、合意が見られる 10 の基本ルールを抽出している。
基礎ルールは次の二つで、著者はこれらに例外を認めない立場を取る。

一つのパラグラフは、一つのトピックについてのみ述べる。
パラグラフは、トピック・センテンスとサポーティング・センテンスで構成する。

続く 8 件は、トピック・センテンスを先頭に置くこと、支持文をトピック・センテンスと関連させること、読み手の標準的な順序意識に沿って情報を配列することなどで、例外を認める扱いになっている。

長さについては 200 字から 400 字、文数で 4 文から 8 文を目安としている。
永井はこの目安の根拠として二点を挙げる。
200 字を 4 文で構成すると一文あたり平均 50 字となり、テクニカルコミュニケーター協会が推奨する一文 50 字以内と対応する。
また 4 文から 8 文という数は、Cowan の 4±1 チャンクと矛盾しない。
なお永井自身は 3 文から 5 文が妥当と考えるが、文献間の合意を優先して 4 文から 8 文としたと注記している。

例外も明示されている。
つなぎの段落や、結論をまとめる総論的な段落は短くなる。

日本語固有の論点として、永井は「段落」と「パラグラフ」の区別を挙げる。
石黒 (2022) を引きながら、日本語の段落には執筆時のルールが確立しておらず、書き手の感覚的な判断で構成されると整理している。
自由度が高い反面、書き手と読み手の共通基盤が崩れやすい。

## 4. 文と文のつなぎ

Clark と Haviland (1977) の given-new contract は、話し手が既知の情報を given として、未知の情報を new として提示し、聞き手も同じ前提で解釈するという合意を指す。
後続研究では、この方略に沿った説明文のほうが、同じ真理値を持ちながら方略に反する文よりも処理しやすいことが確認されている。

Gopen と Swan (1990) は、これを文中の位置に落とし込んだ。
文頭のトピック位置には、前を受ける既知情報を置く。
文末のストレス位置には、強調したい新情報を置く。
両者はこの位置の使い方の誤りを、専門的な科学論文における最大の問題として挙げている。

日本語では語順の自由度が高く、そのまま適用できない部分がある。
「公用文作成の考え方」は、日本語の基本語順を「いつ、どこで、誰が、何を、どうした」とした上で、理解の条件となる内容や強調したい要素を文頭に置くほうが効果的な場合もあるとしている。

## 5. 反証と限界

### 5.1 つながりが良いほど良いとは限らない

McNamara らが報告した reverse cohesion effect は、予備知識の多い読み手では、結束性の低いテキストのほうが学習が進む場合があるという結果である。
説明が省かれている部分を自分で推論することが、理解の深さにつながると解釈されている。
予備知識の少ない読み手では逆に、結束性の高いテキストが知識の欠落を埋める。

その後の研究で条件が絞り込まれている。
O'Reilly と McNamara (2007) は、低結束テキストが有利なのは読解技能の低い高知識読者に限られ、技能の高い高知識読者は高結束テキストからも利益を得ると報告した。

実務上の含意は明確である。
読み手の予備知識を確認せずに「丁寧に説明する」方向へ倒すと、専門家向け文書では逆効果になり得る。

### 5.2 指標は合否判定に使えない

jReadability は、平均文長、漢語率、和語率、動詞率、助詞率から難易度を算出する。
柴崎 (2014) が指摘するように、リーダビリティ指標が扱えるのはテキスト側の要因だけであり、読み手の知識や目的は入らない。

既存の SKILL.md が文長や漢字密度を補助的な警告にとどめているのは、この限界に対応している。
今回の調査でこの方針を変える根拠は見つからなかった。

### 5.3 見出しは万能ではない

前述のとおり、Lorch と Lorch (1996) は単純な構造では signaling の効果を検出していない。
また signaling は話題数の想起を増やす一方で、話題ごとの詳細の想起を減らした。

見出しを増やすほど読みやすくなるという前提は、この結果と整合しない。

## 6. 定義案

以上を踏まえた定義を置く。
根拠の強さで三段階に分ける。

### 6.1 適用条件を選ばないもの

読み手の予備知識と目的を先に決める。
これが決まらないと、以下のすべての判断が確定しない。

文書全体を「結論または要点」と「その根拠」の入れ子として構成する。
節、段落、文のいずれの粒度でも同じ形を取る。

結論を文書の冒頭に置く。
理由、詳細、具体例、細目はその後に置く。

一つの段落で扱う主題は一つにする。
段落の先頭に、その段落の要点を述べる文を置く。

既知の情報から新しい情報へ接続する。
文頭に前を受ける情報を、文末に強調したい情報を置く。

分量の上限を先に決める。

### 6.2 条件付きで適用するもの

見出しは、論点が複数あるか分量が多い場合に付ける。
短い文書や話題構造が単純な文書では、付けないほうがよい場合がある。

見出しだけを順に読んで内容と流れがつかめる状態にする。
標題と見出しを呼応させる。

説明の厚さは読み手の予備知識に合わせる。
予備知識の多い読み手に対しては、補足を減らして推論の余地を残す。
予備知識の少ない読み手に対しては、接続を明示する。

段落は 200 字から 400 字、4 文から 8 文を目安にする。
つなぎの段落と総論の段落は短くてよい。

三つ以上の並列情報は箇条書きにする。
因果や条件でつながる情報は散文のまま書く。

### 6.3 目安にとどめるもの

一文は 50 字から 60 字を超えたあたりで読みにくさを点検する。
数値を超えたことだけを理由に分割しない。

漢字密度、助詞の連続、文末の反復は警告として扱う。
単独では欠陥と判定しない。
