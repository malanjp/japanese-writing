# docs

スキル本体（`SKILL.md` / `references/`）以外の、設計記録と評価を置く。

```text
docs/
├── README.md                 # このファイル
├── design/                   # 設計の根拠と参考資料の反映記録
│   ├── rationale.md
│   └── document-structure-research.md
└── evals/                    # 効果検証
    ├── README.md
    ├── YYYY-MM-DD-<topic>.md
    └── fixtures/             # 評価用の原文・修正稿
```

| パス | 内容 |
|---|---|
| [design/rationale.md](design/rationale.md) | 参考資料をスキルにどう反映したか |
| [design/document-structure-research.md](design/document-structure-research.md) | 文書構成規則の根拠と出典 |
| [evals/](evals/) | 評価レポートとフィクスチャ |

使い方・インストールはリポジトリ直下の [README.md](../README.md)。設計方針は [CLAUDE.md](../CLAUDE.md)。
