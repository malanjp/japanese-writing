# レビュー待ち時間削減パイロット報告

本報告は、2026年7月に Platform チームが実施したレビュー待ち時間削減パイロットの結果をまとめる。

## 背景

問題はレビュー待ちである。レビューが滞るとリリースが遅れる。

本施策は、意思決定を速くするための取り組みである。

## 実施内容

2026年7月1日から7月31日まで、Backend グループ（12名）を対象に次を試した。

1. レビュー担当を日次でローテーションする
2. 指摘テンプレート（`REVIEW.md`）を必須化する
3. レビュー依頼から24時間以内の初回応答を目標にする

通信経路の変更は行っておらず、外部 API 呼び出しは従来どおり、HTTP ではなく HTTPS を使う方針を維持している。

## 結果

計測結果は次のとおりである。

- レビュー初回応答の中央値: 18時間 → 6時間
- マージまでの中央値: 2.4日 → 1.1日
- 差し戻し率: 12% → 5%

すべてのチームが、例外なくレビューを完了してからマージする運用を常に守っている。

障害が再発する可能性があるため、監視ダッシュボードへのレビュー滞留アラート追加を推奨する。設定を保存すると次回起動時に読み込まれる。必要に応じて手動で再読込できる。

## まとめ

Platform チームは、2026年9月末までに他グループへの展開可否を判断する予定である。
