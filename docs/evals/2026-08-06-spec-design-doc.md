## 所見

1. **設計書パターンでも認知順序と AI 癖除去は効く。** 結論のリード化、前提／手順の分離、因果は散文・並列は箇条書き、が揃った。
2. **ジャンル分岐も守れた。** 平坦さの〔助言〕は出さず、仕様向け（見出し対応・表形式）に留まった。
3. **保護対象はすべて保持。**
4. Circuit Breaker の位置づけ曖昧さは〔指摘〕で確認事項にしている（仕様／余談の境界）。追加規則は不要。

## 改善候補

現状なし。仕様書向けの必須チェックを SKILL の自己適用に「目的・前提・操作・例外」と一行足す案はあるが、genre-guidance に既にあるため重複を避ける。
