# 生成AI特有の日本語の癖

Claude を含む言語モデルが日本語を書くときに繰り返し出る癖をまとめる。診断時のチェックリストとして使い、該当箇所だけを直す。癖の除去を目的化して、必要な情報や丁寧さまで削らない。

## 目次

1. 語彙・言い回し
2. 構造・段落
3. 表記
4. 内容の水増しと捏造
5. 検出しにくい癖

---

## 1. 語彙・言い回し

| 癖 | 例 | 直し方 |
|---|---|---|
| 冗長な機能表現 | 〜することができます / 〜を行います / 〜という形になります | 〜できます / 〜します |
| 空の前置き | まずは基本から確認しましょう / 詳しく見ていきます | 削除して本題から始める |
| 定型の強調 | 重要なのは〜という点です / ここでポイントとなるのが | 主張そのものを書く |
| 営業調の動詞 | 〜を実現します / 〜を可能にします / 〜の鍵となります | 何がどう変わるかを具体的に書く |
| 過剰な副詞 | 非常に / 極めて / 圧倒的に / まさに / 劇的に | 削除するか、数値・事実に置き換える |
| 英語直訳の接続 | 〜に関して / 〜という観点から / 〜を通じて | 〜は / 〜で |
| 感情的な枕 | 素晴らしいご質問ですね / 大変興味深い点です | 削除する |
| 過剰な留保 | 一般的には / 場合によっては / あくまで の連発 | 一文につき最大一つに絞る |

**修正例**

- 原文: 本ツールを活用することによって、開発チームは非常に効率的にレビューを行うことが可能になります。
- 修正: 本ツールを使うと、レビューの待ち時間が短くなる。

## 2. 構造・段落

- **過剰な三項列挙**: 常に三つ並べる。三つ目が一つ目の言い換えになっていることが多い。検証できる項目だけ残す。数を揃えるために項目を足さない。
- **言い換えだけのまとめ**: 「以上のように、〜は重要です」で終わる段落。新しい情報がなければ削除する。
- **箇条書きの濫用**: 散文で流れが説明できる内容を箇条書きに割る。因果や条件でつながる情報は文章のまま書く。並列で対等な情報だけ箇条書きにする。
- **箇条書きの不揃い**: 体言止めと文が混在する、粒度が揃っていない。項目内の形式を統一する。
- **見出しの過剰分割**: 2〜3文ごとに見出しが入る。1見出しにつき最低1段落を目安にする。
- **対句・体言止めの過剰**: 「速く、正確に、確実に。」のような装飾。技術文書では削る。
- **太字の濫用**: 一段落に複数の太字がある場合、強調が機能していない。段落あたり最大1箇所を目安にする。

**修正例**

- 原文: 本機能には次の3つのメリットがあります。1つ目は効率化です。2つ目は品質向上です。3つ目は生産性の最大化です。
- 修正: 本機能はレビュー待ち時間を短縮する。差し戻し率の低下も確認されている。

## 3. 表記

- 半角英数字と日本語の間のスペースの有無を、文書内で統一する
- 括弧を全角と半角で混在させない
- 感嘆符、絵文字、「〜」の多用を避ける（媒体が求める場合を除く）
- 敬体（ですます）と常体（である）を混在させない。混在が意図的な文体である場合は保持する
- 三点リーダーは「…」を使い、「...」と混在させない
- 箇条書き末尾の句点の有無を統一する

## 4. 内容の水増しと捏造

生成AIの出力で最も害が大きい。読みやすさより優先して確認する。

- **数値の捏造**: 原文にない「30%改善」「3倍高速」などを補わない。出典がなければ書かない
- **具体例の捏造**: 説明を補強するための架空の事例や企業名を足さない
- **一般論の水増し**: 「近年、〜が注目されています」のような、誰でも書ける導入を足さない
- **根拠のない断定**: 原文が可能性・推奨で書いている内容を、断定・義務に変えない
- **削除による意味の欠落**: 短くする過程で、条件・例外・前提が落ちていないか照合する

## 5. 検出しにくい癖

構造上は正しく見えるが、読むと内容が薄い状態。

- **同義反復の段落**: 前段落と主張が同じで、語彙だけ変えている
- **主語の消失**: 「〜が求められます」「〜が重要とされています」で、誰がそう求めているか不明
- **抽象度の高止まり**: 「最適化」「効率化」「活用」だけで、何をどうするかが書かれていない
- **バランス取りの定型**: 「一方で、注意点もあります」と書いて、実質的な注意点を挙げない
- **数値の方向の取り違え**: 「離脱率が37%まで向上」のように、改善・悪化の向きと語が食い違う。数値と評価語の向きが一致しているか照合する（依頼範囲の扱いは SKILL.md「依頼範囲を超えない」を参照）

**修正例**

- 原文: 近年、AI開発の分野では、開発プロセスの最適化が重要視されています。効率的な運用を実現するためには、適切なツールの活用が求められます。
- 修正: （原文に固有の情報がないため、全削除して本題から始める。削除の可否をユーザーに確認する）
