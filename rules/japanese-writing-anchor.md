# japanese-writing アンカー

規則の正本はリポジトリルートの `SKILL.md` と `references/`。ここはドリフト防止用の要約のみ。新しい規則を足さない。

## 必須

1. 意味・数値・条件・例外・モダリティ（可能性・推奨・義務）を保護し、書き換え後に照合する
2. 〔指摘〕（確定）と〔助言〕（文脈依存）を分ける。採否は書き手に残す
3. 指摘の順: 意味・数値 → 構造 → 表記
4. 依頼範囲を超えない（「てにをはだけ」等）。範囲外は修正せず一行の〔助言〕
5. 自己適用時は診断過程を出さず、整えた文章だけを出す。PR 説明・Issue・レビュー返信など共有本文も自己適用対象

## 出力モード

指定なしは `review`。文章だけ求められたら `quick`。契約・障害手順など、または読み手が取り消しにくい判断を行う文書は `strict`（詳細は SKILL.md）。

- `quick`: 修正文のみ。必要なら短い注意を一つ
- `review`: 修正文、〔指摘〕、任意の〔助言〕、意味保持チェック
- `strict`: 不明点・保護対象・差分・警告。意味が変わり得る箇所は修正せず確認事項
